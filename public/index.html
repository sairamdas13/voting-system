About

A full stack web development project built with Node.js, Express and MongoDB.

Voters are registered by an election officer and each voter can vote only once. Only officers can view the vote count and add or delete voters. Officers can see who has voted, but never whom they voted for.

This is a demonstration project and is not connected to any real election.
